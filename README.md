# Soo Automation

نظام متكامل لتحميل المسلسلات من المواقع الخارجية ورفعها إلى تليجرام.

## التشغيل بضغطة واحدة

```bash
pip install -r requirements.txt
cp .env.example .env
# املأ .env
python run.py
```

## كيف يعمل

1. يفحص الموقع الخارجي لجلب قائمة المسلسلات.
2. لكل مسلسل، يكتشف الحلقات الجديدة (غير المرفوعة).
3. يحمّل كل حلقة بـ yt-dlp (أو requests كبديل).
4. يرفعها إلى قناة تليجرام بالترتيب.
5. يحدّث قاعدة البيانات والموقع بشكل تدريجي.
6. أي خطأ → يوقف كل شيء فوراً.

## الإيقاف عند الخطأ

أي خطأ في أي مرحلة (تحميل، رفع، بناء) يرفع `SooFatalError`
ويوقف جميع العمليات. لن تنتقل للحلقة التالية حتى تُصلح الخطأ.

## البناء التدريجي

- عند إضافة حلقة → يحدّث صفحة المسلسل + `videos.json` فقط.
- لا يعيد بناء الموقع بالكامل.
- `index.html` يُنشأ مرة واحدة فقط.

## المراقبة المستمرة

ضع `CHECK_INTERVAL=3600` في `.env` لفحص الموقع كل ساعة.
